# HTML Portfolio Website

This project is a simple **HTML-based personal portfolio website** created as part of my web development learning journey.

The purpose of this project was to practice and understand the fundamentals of **HTML structure, headings, paragraphs, links, images, lists, and basic website navigation** by building a small multi-page portfolio.

## What I Worked On

* Created the basic HTML document structure using `<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>`.
* Added page headings and subheadings using `<h1>`, `<h2>`, and `<h3>`.
* Used paragraphs with `<p>` to provide descriptions and information.
* Created hyperlinks using the `<a>` tag to navigate between different projects and pages.
* Added images using the `<img>` tag with alternative text using the `alt` attribute.
* Created unordered lists using `<ul>` and `<li>`.
* Used horizontal lines with `<hr>` to separate sections.
* Created separate pages such as **About Me** and **Contact**.
* Organized projects into separate folders and linked them from the main portfolio page.
* Practiced using relative paths such as `./public/...` for navigating between project files.
* Added an external Google Maps link as part of the Birthday Invitation project.
* Used the viewport meta tag to make the page suitable for different screen sizes.
