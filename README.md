# HTML Portfolio & Resume Projects


## About This Repository

This repository contains the HTML projects and exercises I have completed while learning the fundamentals of **Web Development and HTML5**.

The projects focus on building webpages from scratch and practicing HTML document structure, text formatting, links, images, lists, navigation, and organizing content across multiple pages.

---

## Projects & Exercises

### 1. HTML Portfolio Website

I created a basic portfolio website to practice building a multi-section webpage using HTML.

#### Work completed:

* Created the main portfolio webpage.
* Added a personal portfolio heading and web developer introduction.
* Created a **Movie Ranking Project** section.
* Created a **Birthday Invite Project**.
* Added images using the `<img>` element.
* Added project navigation using the `<a>` element.
* Created an **About Me** page.
* Created a **Contact** page.
* Added an external Google Maps link.
* Practiced organizing project files using folders and relative paths.

#### HTML concepts practiced:

* HTML document structure
* Headings
* Paragraphs
* Horizontal rules
* Images
* Hyperlinks
* Unordered lists
* Relative file paths
* External links
* Multi-page navigation

### 2. HTML Resume / CV Exercise

I also created a resume-style webpage to practice structuring professional information using HTML.

The exercise contains sections for:

* Summary
* Education
* Work Experience
* Skills
* Awards and Certifications
* Hobbies
* Contact Information

I practiced organizing resume information using headings, paragraphs, unordered lists, links, and images.

#### HTML concepts practiced:

* Structuring a resume using semantic sections
* Using different heading levels such as `<h1>` and `<h2>`
* Creating lists with `<ul>` and `<li>`
* Adding profile images
* Creating links to additional pages
* Creating separate Hobbies and Contact pages
* Organizing content in a readable webpage format
